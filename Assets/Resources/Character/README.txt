Chibi Volleyball Player - Unity prototype

Files:
- ChibiVolleyballPlayer.obj
- ChibiVolleyballPlayer.mtl

Design:
- Original chibi volleyball player
- Approx. 1.9 Unity units including hair
- Y-up
- A-pose-ish arms for easier later rigging
- Separate named objects for body parts, clothing, hair, eyes and volleyball
- No rig / bones / animations (OBJ format cannot contain them)

Unity:
1. Put OBJ and MTL together under Assets.
2. Import the OBJ.
3. If materials do not map perfectly, create Unity materials using the MTL colors.
4. For animation, import into Blender, join/clean meshes as desired, rig, weight paint, then export FBX as Humanoid.
